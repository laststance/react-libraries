## What it does

Table logic for sorting, filtering, and pagination, with complete control over your UI.

## When it fits

A custom table that fits your existing design system.

## What you build

Render rows and cells using your own components. Connect search, sort, and filter controls to table state. For large datasets, decide between client-side data, server-side operations, and a separate virtualization layer.

## Keep in mind

You build the markup and controls; virtualization is a separate concern.
